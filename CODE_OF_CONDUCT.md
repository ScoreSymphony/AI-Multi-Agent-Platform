# Code of Conduct

## Expected conduct

Participants must communicate respectfully, critique ideas and changes rather than people, disclose relevant conflicts of interest, and keep technical discussions focused on evidence and project goals.

Harassment, discrimination, threats, doxxing, sexualized conduct, deliberate intimidation and publication of private or security-sensitive information are not acceptable.

## Scope

This policy applies to issues, pull requests, reviews, discussions and other spaces used to represent this project. It also applies when someone represents the project in another public or private forum.

## Reporting and enforcement

Report conduct concerns privately to the repository maintainer. Security vulnerabilities must use the private process in `SECURITY.md` and must not be included in a conduct report or public issue.

The maintainer may edit or remove content, limit participation, lock a conversation or ban a participant when necessary to protect contributors and the project. Enforcement should be proportionate, documented privately when appropriate and applied without retaliation against good-faith reporters.
