## Architecture gate

The maintained Web client uses the public versioned Control Plane and shared typed browser transport.
It does not call Worker/provider-private services directly. React state is presentation state only;
durable lifecycle state is re-read by canonical ID. Marketplace, Search, telemetry, Research and
Decision projections do not become shadow lifecycle authorities.

## Final validation gate

This matrix is implementation evidence, not permission to merge. The exact final integration head
must pass generated-contract checks, frontend transport-boundary checks, TypeScript, Vitest,
production build, representative browser regression including the maintained #1164 first-run path,
repository-required checks and review/merge blockers. #1234 remains open until that exact-head
validation succeeds.
